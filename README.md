# TTS-Sidecar - TTS-Sidecar: Microservice Voice Synthesis

---

### 🌐 English

Lightweight sidecar service delivering real-time Text-to-Speech audio synthesis for AI assistants and conversational interfaces.

#### Key Features:
* Low-latency audio stream generation
* REST API integration
* Multi-voice & tone support

* **Tech Stack**: `Python` `FastAPI` `TTS Engines` `Docker`

---

### 🌐 Español
